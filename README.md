# 💅 ربات تلگرام کارشناس زیبایی و آرایشگری

مشاور شخصی شما برای زیبایی و آرایش!

این ربات با محبت و با تخصص کامل در حوزه آرایشگری و مراقبت از پوست و مو، آماده پاسخگویی به تمام سوالات زیبایی و بهداشتی شماست.

## ✨ خدمات و مشاوره‌ها

- 🔍 **تشخیص نوع پوست و مو**: آنالیز دقیق پوست و موی شما
- 🧼 **مراقبت پوست**: روتین مراقبت روزانه و شبانه
- 💈 **آرایش و زیبایی**: پیشنهاد آرایش مناسب فرم صورت
- 🔥 **مشکلات پوستی**: راهکار آکنه، لک‌های پیری، خشکی
- ✌️ **مدل و رنگ مو**: انتخاب بهترین مدل برای فرم صورت
- 🍿 **تغذیه زیبایی**: رازهای زیبایی از درون
- 🛋️ **مراقبت خانگی**: طرز تهیه ماسک و پک طبیعی
- 💎 **انتخاب محصولات**: راهنمایی برای برندها و محصولات

## 📋 پیش‌نیازها

- Python 3.7 یا بالاتر
- اتصال اینترنت
- حساب کاربری تلگرام

## 🚀 راه‌اندازی

### مرحله 1: دریافت API اطلاعات تلگرام

1. به آدرس https://my.telegram.org مراجعه کنید
2. با شماره تلفن خود وارد شوید
3. به بخش "API development tools" بروید
4. یک Application جدید ایجاد کنید
5. `API_ID` و `API_HASH` را یادداشت کنید

### مرحله 2: تنظیم پروژه

1. فایل `config.py` را ویرایش کنید:
```python
API_ID = 123456  # API ID دریافتی از تلگرام
API_HASH = 'your_api_hash_here'  # API Hash دریافتی
PHONE_NUMBER = '+989123456789'  # شماره تلفن شما
```

### مرحله 3: نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### مرحله 4: اجرای ربات

```bash
python main.py
```
